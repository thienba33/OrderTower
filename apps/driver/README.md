# Web tài xế (màn hình tối thiểu)

Web mobile đơn giản, chỉ đơn được giao cho chính tài xế đó. Tài xế cập nhật
trạng thái giao hàng và gửi ảnh bằng chứng. Không GPS, không tối ưu tuyến
đường, không xem đơn của người khác.

Ảnh bằng chứng gửi qua API, qua kiểm dịch ở cửa ngõ rồi mới lưu vào kho đối
tượng, chỉ lưu tham chiếu và hash ở cơ sở dữ liệu chính.
